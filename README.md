# 🤖 AI Text Sentiment & Emotion Analyzer

An interactive Web Application that analyzes the sentiment and emotional tone of user-provided text in real-time using Deep Learning and Natural Language Processing (NLP).

---

## 🌟 Features
* ⚡ **Real-Time Analysis:** Instantly classifies text as **Positive** or **Negative**.
* 📊 **Confidence Score:** Displays the model's accuracy percentage for every prediction.
* 🎨 **User-Friendly UI:** Built with Streamlit for a clean, minimal, and modern interface.
* 🚀 **Model Caching:** Uses `@st.cache_resource` for fast performance and instant loading.

---

## 🛠️ Tech Stack & Tools
* **Programming Language:** Python 🐍
* **Framework:** Streamlit 🎈
* **Machine Learning / NLP:** Hugging Face `transformers`, PyTorch (`torch`) 🤖
* **Development:** Google Colab 💻
* **Deployment:** Streamlit Cloud ☁️
